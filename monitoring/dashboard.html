The SMTP password

The app password lives in Google Secret Manager as ARIAL_SMTP_PASS, never in the database and never in this page - a browser cannot read or write it. Set or rotate it there, then redeploy the functions so they pick up the new version.

After changing it, run firebase deploy --only functions, then use “Send test mail” above to confirm it works.

What this page does not cover

These numbers are bytes written through sync. They do not include reads, hosting, or storage — most of what actually gets billed as egress. For that, set a billing budget and a Cloud Monitoring alert on the project; both mail you directly and need no code.
