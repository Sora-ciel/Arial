# Asset licence

[`LICENSE.txt`](LICENSE.txt) — the MIT licence — covers the **source code** of
this app. It does not cover the artwork listed below.

## Not covered by MIT

| path | what |
| --- | --- |
| `public/hato/*.webp` | the Hato pigeon-hoodie wallpapers, rescaled and cropped |
| `public/hato/buddies/*.png` | characters cut out of those wallpapers, used as toolbar icons |

Both are the same illustration: the `buddies` files are crops of it, so they
are derivative works and carry the same terms.

**Artwork © 2025 Sora-ciel. All rights reserved.**

The illustration is included here for use inside this app. It is not licensed
for reuse, redistribution, or modification apart from the app, and receiving a

## Why this file exists

MIT, as written in `LICENSE.txt`, grants everyone the right to reuse
everything in the repository — including the artwork, commercially and without
attribution. That is rarely what you want for original illustration, so the
art is held back while the code stays MIT.

If you would rather let MIT cover the artwork too, delete this file and the
**Licence** section of [`README.md`](README.md); nothing else depends on it.

## Removing the artwork

The Mr.Lee theme is a guest theme and is meant to be taken back out. Deleting
`public/hato/` and following [`HATO_THEME.md`](HATO_THEME.md) removes every
file listed above, after which the MIT licence covers the whole repository on
its own.
