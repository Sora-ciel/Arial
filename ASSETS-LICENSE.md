# Asset licence

[`LICENSE.txt`](LICENSE.txt) — the PolyForm Noncommercial licence — covers the
**source code** of this app. It does not cover the artwork listed below.

## Not covered by the source licence

| path | what |
| --- | --- |
| `public/hato/*.webp` | the Hato pigeon-hoodie wallpapers, rescaled and cropped |
| `public/hato/buddies/*.png` | characters cut out of those wallpapers, used as toolbar icons |

Both are the same illustration: the `buddies` files are crops of it, so they
are derivative works and carry the same terms.

## Why this file exists

The source licence lets anyone copy, change and redistribute what is in this
repository for any noncommercial purpose. That is the intention for the code.
It is rarely the intention for original illustration, which people would then
be free to lift out, alter and pass around on its own, so the art is held back
separately.

This was true under MIT before, and more so: MIT allowed all of that
commercially as well. Narrowing the code licence has not made the artwork any
freer, and the terms here have not changed — the art has always been all rights
reserved.

If you would rather let the source licence cover the artwork too, delete this
file and the **Licence** section of [`README.md`](README.md); nothing else
depends on it.

## Removing the artwork

The Mr.Lee theme is a guest theme and is meant to be taken back out. Deleting
`public/hato/` and following [`HATO_THEME.md`](HATO_THEME.md) removes every
file listed above, after which [`LICENSE.txt`](LICENSE.txt) covers the whole
repository on its own.
